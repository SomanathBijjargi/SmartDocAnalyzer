# 🚀 Smart Document Analyzer — AI SaaS Platform

An intelligent AI-powered SaaS web application that allows users to upload documents (PDF, images, handwritten notes) and automatically extract, analyze, and interact with content using advanced OCR and AI.

Built with modern full-stack + AI microservice architecture.

---

# 🌟 Features

## 🔐 Authentication System
- User signup & login (JWT authentication)
- Secure protected routes
- Google login support (planned)

## 📂 Document Upload System
- Upload images & PDFs
- Secure user-based storage
- Document history dashboard

## 🤖 AI Document Processing (In Progress)
- OCR text extraction (PaddleOCR + DocTR)
- Handwritten text recognition
- AI text cleaning & correction
- Table extraction
- Document summary generation

## 💬 Chat with Document (Upcoming)
- Ask questions from uploaded document
- AI answers using document context
- Smart search inside documents

## ☁️ Cloud & SaaS Ready
- MongoDB Atlas cloud database
- JWT authentication
- Microservice architecture
- Scalable backend

# 🏗️ Tech Stack

## 🟢 Backend

## 🤖 AI Engine (Python)
- PaddleOCR  
- DocTR  
- OpenCV  
- FastAPI (AI microservice)  
- NLP & LLM integration (upcoming)
